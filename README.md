# OpenLint legacy Spectral Arazzo ruleset

Compatibility package for the original `spectral:arazzo` ruleset. It preserves
the full legacy Arazzo ruleset for existing configurations and JavaScript API
consumers.

Install the package and extend it directly:

```sh
npm install --save-dev @openlint/ruleset-spectral-arazzo
```

```yaml
extends: "spectral:arazzo"
```
